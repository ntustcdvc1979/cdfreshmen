組別
開場畫面

投影幕在待機時有五頁，用 → / ← 翻（主持人控制台也翻得動）：
黑畫面 → 開場影片 → 主視覺 → 遊戲規則 → 掃碼進場（含各組代表就位狀況）。

留空的話會用內建的流程示意圖（台下學員 → 代表 → 確認送出 → 計分）， 不會開天窗。填了就換成你自己的圖。

題目
編輯題目

預設 1 分：代表答對 +1、學員答對過半 +1，兩筆各算各的 （代表沒送出，學員過半照樣拿分）。改成 N 就變成各 +N。 只有不是 1 的時候，投影幕才會在題號旁顯示 +N。

公布答案後的說明　會跟正解同時出現在投影幕上。 下面一格一格排，半行的區塊會自動並排成兩欄。

下面是投影幕上的實際排版預覽：

兩個圖片欄位都是選填，可以只填一個、也可以都填。 說明圖片會跟說明文字併排在同一頁；整頁大圖會單獨佔滿一整個投影畫面， 適合放流程圖、對照表這種需要看細節的東西。
圖片有兩種放法：①貼一個外部圖片直連網址； ②把檔案放進 repo 的 assets/img/explain/，這裡填 assets/img/explain/檔名.webp。

說明音檔跟整頁大圖是同一頁：大圖鋪滿畫面、音檔在底下播， 適合放旁白或一段訪談。只播一次，不會重播，翻到別頁就停； 播的時候講解背景音樂會自動讓開，畫面下方會有「🔊 說明音檔播放中」。
沒填整頁大圖、只填音檔也可以 —— 那一頁就純粹放音檔。 整頁大圖填的是影片時，影片自己有聲音，說明音檔就會略過不播。
檔案放進 repo 的 assets/audio/，這裡填 assets/audio/檔名.mp3（也可以貼外部音檔直連網址）。
